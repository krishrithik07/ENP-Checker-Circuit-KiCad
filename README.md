# Earth–Neutral–Phase (ENP) Checker Circuit

**KiCad | Circuit Design | LED Indication**

## Project Overview

This project involves designing an Earth–Neutral–Phase (ENP) checker circuit using KiCad. The circuit uses three LED branches with diode and resistor networks to provide visual indication.

## Components Used

- 3-pin connector
- LEDs – 3
- 1N4007 diodes – 3
- 100KΩ resistors – 3

## Design Tools

- KiCad – Schematic Design
- KiCad PCB Editor – PCB Layout (if completed)

## Project Features

- Three LED indicator branches.
- Diode-based circuit configuration.
- Three-pin input connection.
